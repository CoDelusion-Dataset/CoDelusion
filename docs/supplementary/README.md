# Supplementary Material

Supplementary material for the paper *Decoding Delusions: An Empirical Study on LLM Code Hallucination*, also submitted to the journal as Online Resource 1. Section and table numbers (S1–S5, Tables S1–S13) follow the PDF.

| File | Content |
|---|---|
| [`prompts.md`](prompts.md) | S1: generation prompts and the type-classification prompt |
| [`type_classification_prompt.txt`](type_classification_prompt.txt) | The type-classification prompt as plain text; replace `{{TASK_SPEC}}` with the task statement and interface and `{{NUMBERED_CODE}}` with the line-numbered model output |
| [`annotation_guideline_and_cases.md`](annotation_guideline_and_cases.md) | S2: annotation guidelines and reuse protocol; S3: adjudication cases for confusable category boundaries |
| [`supplementary_experiments.md`](supplementary_experiments.md) | S4: temperature-control experiment; S5: type-classification evaluation rules and per-category results |
| [`CoDelusion_Online_Resource_1.pdf`](CoDelusion_Online_Resource_1.pdf) | PDF version of S1–S5 |
